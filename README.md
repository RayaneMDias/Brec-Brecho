# PI-JovemProgramador-Brec-Brecho
# Sistema de Gestão para Brechó (Brec-Brecho)## 

💻 Sobre o Projeto
Sistema desenvolvido para gerenciamento de um brechó, permitindo o controle de peças e vendas. 
O objetivo principal deste projeto foi praticar a integração entre o Back-end (Java) e o Front-end (HTML), 
além da conexão com Banco de Dados.

## 🛠 Tecnologias Utilizadas
**Java** (Lógica e Back-end)
**HTML/CSS** (Interface do usuário)
**MySQL** (Banco de Dados)
**Git/GitHub** (Versionamento de código)

## 📚 O que aprendemos
*Como conectar uma aplicação Java com banco de dados MySQL. 
*Gerenciamento de dados em ambiente local e nuvem.
*Estruturação de projeto em camadas (MVC).
*Versionamento de código utilizando Git e GitHub via terminal.
